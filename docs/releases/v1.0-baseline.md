## 5. Core Flow

The implemented data chain is:

```text
Subject / Knowledge Point
          ↓
     Question Draft
          ↓
       Question
          ↓
     Mistake Draft
          ↓
       Mistake
          ↓
    Review Item
          ↓
   Review Record
```

Private attachments can be linked to question drafts, questions and mistakes. Existing local-trial records previously exercised the core flow with private sample data. Phase 0 did not repeat any write operation.

Current public/legacy routes and newer `/manage/**` workspace routes coexist. The intended read-only demo remains:

1. Public Read: `/`, `/blog`, `/notes`, `/mistakes`.
2. Private Manage: `/manage` then dashboard/questions/mistakes/review/attachments with a real admin session.
3. Core Learning Loop: inspect existing Subject → Question → Mistake → Review records.
4. Attachment Closure: inspect existing private upload/link/read evidence.
