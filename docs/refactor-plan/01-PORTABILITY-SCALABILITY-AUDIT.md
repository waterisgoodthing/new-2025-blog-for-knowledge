### 2.2 性能瓶颈识别

#### 2.2.1 文件上传瓶颈

**位置**: `backend/app/routers/notes.py:112-139`

**问题**:
```python
# 同步文件写入，阻塞请求
file.save(file_path)
```

**影响**: 
- 大文件上传阻塞 worker 线程
- 多实例部署时文件分散
- 无法利用对象存储的并发优势

**改进建议**:
- 异步文件 I/O
- 迁移到对象存储（S3/OSS）
- 实现分片上传

#### 2.2.2 AI 调用瓶颈

**位置**: `backend/app/services/ai_service.py`

**问题**:
- 同步 HTTP 调用外部 AI 服务
- 无超时控制
- 无重试机制
- 无结果缓存

**影响**: 
- 高延迟请求阻塞后端
- 外部服务故障影响整体可用性

**改进建议**:
- 异步调用 + 超时控制
- 实现断路器模式（Circuit Breaker）
- 缓存重复请求结果
- 考虑异步任务队列处理

#### 2.2.3 GitHub Sync 瓶颈

**位置**: `backend/app/services/github_sync.py`

**问题**:
- 大量串行 API 调用
- 无并发控制
- 同步阻塞操作

**影响**: 
- 大批量同步耗时长
- 阻塞其他请求

**改进建议**:
- 迁移到后台任务队列
- 批量操作并发化
- 实现进度追踪
