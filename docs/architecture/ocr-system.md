# OCR System

> 状态：拟新增；OCR 输出不是业务事实。

## 职责与边界

OCR 负责识别文字、公式、表格和版面，并保存可追踪结果；它不判断内容属于题目、错题或练习，也不直接创建正式业务实体。

第一版可按能力选择 PaddleOCR 处理普通图片题目、MinerU 处理复杂 PDF/讲义/教材，并将百度 OCR 或腾讯 OCR 作为云端高精度兜底。具体供应商选择待实现阶段验证，不构成依赖批准。

## 核心表

- `ocr_jobs`：附件、引擎、状态、版本、进度、错误、重试和耗时。
- `ocr_results`：完整文本、页级结构、质量分、语言和结果版本。
- `ocr_blocks`：页码、顺序、坐标、文本、置信度与块类型。

块类型：`title`、`paragraph`、`question`、`option`、`answer`、`table`、`formula`、`image`、`annotation`、`handwriting`、`unknown`。

## 处理规则

原附件不可被 OCR 结果替代；低置信度、公式和手写块必须保留警告；重跑产生新结果版本，不覆盖审计历史。成功结果交给 Capture Router 或人工审核。

## 第一版范围

图片/PDF、页级与块级结果、失败重试、人工查看、引擎/版本记录和质量指标。

## 暂缓范围

音视频转写、本地大模型、复杂手写批改和无审核直接入库。
