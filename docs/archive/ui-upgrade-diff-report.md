## 1. 比对方法

对每个问题，逐行审计相关代码，确认：

- 根因是否与用户描述一致

- 是否有遗漏的关联问题

## 2. 逐项比对

### D-01: 左侧导航栏溢出

| 维度 | 用户描述 | 实际代码 | 差异 |
|------|----------|----------|------|
| 问题 | 部分页面被裁切、贴边过近 | `vertical-nav.tsx:48` `fixed left-0 top-1/2 -translate-y-1/2`，无 `max-height` | **确认**：无高度约束 |
| 内容区遮挡 | 内容区被导航遮挡 | `layout/index.tsx:65` `<main>` 无 `padding-left` | **部分确认**：VerticalNav 是 fixed 定位，不占据文档流，但可能遮挡左侧 56px 区域 |
| 统一定位 | /、/notes、/mistakes、/manage 统一 | VerticalNav 在所有内页统一渲染（`layout/index.tsx:63`） | **确认**：已统一 |
| 贴边过近 | 导航贴边 | `left-0` 直接贴边，无 margin | **确认**：无左侧间距 |

**结论**: 问题确认。根因是无 `max-height` 约束和无 `overflow-y-auto`。

**补充发现**:
- `vertical-nav.tsx:54` 内层 `div` 有 `py-3` 但无 `overflow-y-auto`
- 7 个导航项 × 约 40px 高度 = 280px + 头像区域约 50px = 330px
- 在 768px 高度屏幕上不会溢出，但在小笔记本（600px 高度）或分屏模式下可能溢出
- 真正的溢出场景：`top-1/2 -translate-y-1/2` 在 600px 屏幕上居中后，上下各 300px，导航 330px 不会溢出
- **实际更可能的问题**：不是垂直溢出，而是水平贴边过近（`left-0` 无间距）

**修正设计**: 除了添加 `max-height` + `overflow-y-auto`，还应考虑添加 `left-2` 或 `ml-2` 给一点左侧间距。

### D-02: 导航跳转失效

| 维度 | 用户描述 | 实际代码 | 差异 |
|------|----------|----------|------|
| 点击后不跳转 | 点击"错题"后其他导航不跳转 | `vertical-nav.tsx:95-130` 使用 `<Link>` 包裹 | **需验证**：可能是浏览器路由问题 |
| 遮罩层 | 可能有遮罩层拦截 | 无遮罩层代码 | **不确认**：无遮罩层 |
| active 状态 | active 状态干扰 | `motion.div` with `layoutId` 作为 absolute 覆盖 | **可能**：需确认 pointer-events |
| pointer events | pointer 事件问题 | `motion.div` 无显式 `pointer-events-none` | **确认**：motion 默认不设置 pointer-events |

**结论**: 问题可能真实存在，但根因需要进一步验证。

**可能的根因**:
1. `motion.div` with `layoutId='vertical-nav-active'` 在 Framer Motion 中会创建一个 overlay 元素，虽然它在 `Link` 内部，但 `absolute inset-0` 可能覆盖整个点击区域
2. `AnimatePresence` 中 `motion.span` 的 `width: 0` → `width: 'auto'` 动画可能导致布局重排，使点击目标偏移
3. Next.js `Link` 组件在某些情况下可能与 motion 动画冲突

**修正设计**: 
- 给 `motion.div` 添加 `pointer-events-none`
- 将标签动画从 `width` 改为 `opacity + x` 位移
- 确保 `Link` 有 `relative z-10`

**修正设计**: 
- 保持头像+标题跳转首页不变

- 点击调用 `setConfigDialogOpen(true)`

### D-05: 思维导图渲染失败

| 维度 | 用户描述 | 实际代码 | 差异 |
|------|----------|----------|------|
| 渲染失败 | 存在渲染失败 | `markmap-block.tsx:68` `error` state | **确认**：有错误处理 |
| Mermaid 效果差 | Mermaid 思维导图效果差 | 已有 MarkmapBlock 组件 | **确认**：已切换到 Markmap |
| SSR/CSR 冲突 | 可能存在 SSR 冲突 | `'use client'` 已标注 | **部分确认**：有 client 标注但懒加载可能在 SSR 阶段失败 |

| 维度 | 用户描述 | 实际代码 | 差异 |

## 4. 设计修正建议

基于差异分析，以下设计方案需要调整：

| # | 原设计 | 修正 |
|---|--------|------|
| 1 | 添加 max-height + overflow-y-auto | 增加 `left-2` 左侧间距 + 水平裁切验收 |
| 2 | pointer-events-none + 动画改为 opacity+x | 需要实际测试验证 |
| 3 | 添加"网站设置"导航项 | 确认 `setConfigDialogOpen` 可用 |
| 4 | 增加分步 AI 按钮 | 补充启用条件、loading、失败处理、二次确认 |
| 6 | 标题 # 变淡 | 改为默认移除装饰 |
| 7 | 首页按钮动态文案 | 建议保持不变，各页面已有独立入口 |
| 8 | 标签仅补空状态 | 改为按页面类型过滤 + 空状态 |
| 11 | 未涉及 | 新增 /manage 设置集中化 |
