NOT silently write blog_v2 — the new `backend/tests/conftest.py` guard aborts the
run (exit 2) before any test executes, and blog_v2 row counts are unchanged.

Guard mechanism: backend/tests/conftest.py collects every test, classifies
DB-touching files (implicit `from app.database import ...` -> app.database engine
URL; explicit `create_engine(os.environ["DATABASE_URL"])` -> env DATABASE_URL),
and aborts with pytest.exit(..., returncode=2) before any test executes if the
effective target database is not on `^astra_week3_[a-z0-9_]+$`.
