## 主 agent 追加的实现约束（含 W3-D06～D09 定版）

1. 迁移顺序遵守 W3-D02；工具与 dry-run 先于冻结。
2. 公共 DTO 字段严格等于 W3-D03 allowlist；任何新增字段须回到主 agent 重新定版。
3. ledger 新 mapping version 须可 dry-run、可幂等重放、可输出机器可读对账报告（JSON）。
4. 公共页切换后禁止 legacy 回退；若 scratch 验证失败，应回滚切换而不是加 fallback。
5. **W3-D06 映射矩阵**：`status='published' AND hidden=false` → canonical `active`+`public`；其余三格 → `active`+`private`。canonical `status` 是学习生命周期，不得用 legacy 发布态驱动。
6. **W3-D07**：mapping_version = `wk3-mistake-visibility-v1`。`v1-*` ledger/产物保留；未迁移 note 按矩阵新建 canonical 链；已迁移目标只幂等 UPDATE `mistakes.visibility`，记入对账报告，不建重复 ledger 目标行。
7. **W3-D08**：ReviewItem 用 `fixed_interval_v2`；禁拷 SM-2 ef/interval/repetitions 为 v2 状态；v2 默认调度 + `next_review`→`next_due`；LSR03 中 `fixed_interval_v1`/`v1-*` 断言改写。
8. **W3-D09 冻结范围 F-1～F-9 全写入冻结**（create/update-type/promote/两 UI 表单/write-note 内容写/SM-2 提交/字段更新/delete）；兼容读 K-1～K-12 保留；UI 不得对 type='mistake' 行提供写入口。
9. **dry-run 零持久化**（W3F-07）：不得留下 pending_mapping 行；用事务回滚或只写报告文件。
10. **对账报告 JSON schema**（W3F-08）：
    ```json
    {
      "mapping_version": "wk3-mistake-visibility-v1",
      "generated_at": "ISO-8601",
    ```

## 主 agent 定版补遗（2026-09-22，W3-D06～D09）

- **W3-D06 映射矩阵**：`status='published' AND hidden=false` → `active`+`public`；published×hidden、unpublished×visible、unpublished×hidden → `active`+`private`。canonical `status` 只表 active/archived，不得用 legacy 发布态驱动归档。
- **W3-D07 mapping version**：`wk3-mistake-visibility-v1`。`v1-*` ledger/产物保留；新 mapping 对未迁移行创建完整链，对已迁移行**仅 UPDATE `mistakes.visibility`**（幂等），对账事件不占用 target UNIQUE。
- **W3-D08 ReviewItem**：`fixed_interval_v2` + v2 默认调度；`next_review`→`next_due`；禁拷 ef/interval/repetitions；LSR03/测试中 v1 断言同步改写。
