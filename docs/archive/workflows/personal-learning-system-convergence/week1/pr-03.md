## 1. 设计核对

- 依据 `design.md` D11 与 `ui-design.md` §§13-14，新建唯一共享 `src/components/async-state-panel.tsx`，只承担数据面板 loading / empty / error；路由级异常继续使用 App Router `loading.tsx` / `error.tsx` 与 `reset`。
- API error 优先于 empty；可恢复错误必须提供 Retry。Retry pending 时禁用按钮并设置 `aria-busy`，防止重复请求。
- loading 使用稳定 skeleton，`motion-reduce:animate-none` 禁用呼吸动画。error 使用 live alert；恢复成功后焦点进入结果区域。
- 展示安全详情：显式安全字符串和既有 `ApiError` 消息可显示，任意运行时 `Error.message` 不直接暴露。
- Week 1 仅接入公共 `/notes`、Dashboard 主摘要与个人资料面板。既有 `FeatureState` 的三态委托共享组件；`deferred` 兼容语义保留，避免全站扩改。
