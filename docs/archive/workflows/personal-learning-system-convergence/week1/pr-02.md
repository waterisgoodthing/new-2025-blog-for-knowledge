## 1. 设计（2026-09-08 定版）

### 1.1 路由（全部置于 `src/app/manage/(workspace)/notes/`，继承组 layout 的 AuthGate 与导航壳）

| 路由 | 文件 | 行为 |
| --- | --- | --- |
| `/manage/notes` | `page.tsx` | 列表页；`?type=note\|blog` 过滤（缺省全部）；列：标题/类型/状态/更新时间；行动作：编辑→`/manage/notes/[slug]`、查看→`getContentDetailHref`、删除（confirm 后 `deleteNote`）；新建按钮→`/manage/notes/new?type=note\|blog`。数据经 `useNoteIndex`（SWR）；状态用既有 `FeatureState`（loading/empty/error 自带）。 |
| `/manage/notes/new` | `new/page.tsx` | 新建；`?type=note|blog`（默认 note，非法值回落 note）；挂 `<ContentEditor mode="create" type=…>`；Suspense 包裹（useSearchParams）。 |
| `/manage/notes/[slug]` | `[slug]/page.tsx` | 编辑；`getNote(slug)` 载入，`updateNote(slug, { expected_revision, … })` 保存（乐观并发，F16 语义不变）；404 → `EmptyState variant="load-error"`。 |

### 1.2 ContentEditor（唯一编辑器组件，`notes/components/content-editor.tsx`）

- Props：`{ mode: 'create'|'edit'; type: 'note'|'blog'; initial?: { slug; title; content; summary?; tags?; category?; hidden?; status? } }`；不直连 fetch——经 `src/lib/api/notes.ts` / `meta.ts`。
- **构图（§8.1）**：正文 textarea 为最大独立模块（`useNoteEditor` 引擎，迁至 `src/hooks/use-note-editor.ts`，旧路径 `src/app/write-note/hooks/use-note-editor.ts` 留 re-export shim）；短标题框、保存状态框、属性框、发布框散落为独立方框；无包大卡片、无常驻格式工具栏。§8.3 选区工具与 §8.6 AI 不在本切片（tasks.md PR-02 列明四项：构图/保存状态/属性/发布确认）。
- **保存状态（§8.4 子集）**：独立小框，`editing`（中性）/`saving`（透明度呼吸，`prefers-reduced-motion` 下静态）/`saved`（品牌色后收小）/`failed`（红 + 重试）；切换不清空输入；仅 canonical 持久化成功才显 saved。`Ctrl/Cmd+S` 保存。conflict（409）按 failed 呈现并透出服务端信息（完整 conflict UX 不在本切片，记录取舍）。
- **属性（§8.5 子集）**：默认单一摘要框（显示 tags 数/分类/可见性概要）；点击展开为独立小框：TagInput（组件迁至 `src/components/tag-input.tsx`，旧路径留 shim）、blog 增 summary+category（`listCategories()` + 既有 `Select`）、visibility（`hidden` checkbox）；保存或点击空白聚合；焦点错误时不聚合。note 类型无 summary/category。
- **发布（§8.7 子集）**：低调小框显示当前状态；条件满足（标题+正文非空）点亮"发布"；点击弹确认 Modal（最小实现：遮罩+对话框，打开移焦点、Escape 取消、关闭还焦）；确认后以 `status:'published'` 保存；失败保留内容并显示真实服务端状态。**满足条件不代表自动发布**。
- **slug 生成（客户端）**：由短标题 slugify（保留 CJK、空白转 `-`、空/全空时回落 `note-<date><rand4>`）；服务端 `ensure_n`（routers/notes.py）负责归一化与唯一性——沿用现状语义，不改 API（F16/D10）。编辑模式 slug 不可改。
- 样式：既有 token（`--color-brand` 等）、`brand-btn`、Tailwind；复用 `EmptyState`/`Select`；无新依赖。

### 1.3 旧路由三阶段（本 PR 做 ①redirect 重定向 ②内部链接迁移；③删除旧目录另行批准，不动 `src/app/write*/`）

- `next.config.ts` redirects 重定向目标修订（D10）：
  - `/write-note` → `/manage/notes/new?type=note`；`/write-note/:slug` → `/manage/notes/:slug`
  - `/write` → `/manage/notes/new?type=blog`；`/write/:slug` → `/manage/notes/:slug`
  - `/write-mistake*` 两条维持现状（R04 处置）
- 内部链接：`dashboard-overview.tsx` 快捷动作 `/write-note`→`/manage/notes/new?type=note`、`/write`→`/manage/notes/new?type=blog`；`content-routes.ts` `getContentEditHref` note/blog → `` `/manage/notes/${slug}` ``（mistake 保持 `/manage/mistakes`）。
- 契约测试同步：`batch7-compatibility.test.ts` 第 3 例改为断言新 edit href（write 页存在性断言保留）；第 4 例追加新 redirect 断言；`dashboard-overview.test.tsx` href 断言同步。
- 侧边栏（D-W1-4）：`manage-sidebar.tsx` "内容管理"组首位加 `笔记写作 → /manage/notes`（icon `NotebookPen`，match `startsWith('/manage/notes')`）。

### 1.4 不做（BLOCK/越界即停）

不删 `src/app/write*/`；不改 notes API/DTO；不做封面/图片上传切片；不做 AI 辅助/选区工具；不动 `AuthGate` 语义；不建新编辑器分叉（只此一个 ContentEditor）。
