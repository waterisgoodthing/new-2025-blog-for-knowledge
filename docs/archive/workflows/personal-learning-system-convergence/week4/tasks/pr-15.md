## Objective

Replace the three global in-memory challenge dictionaries with a database-backed lifecycle that prevents challenge reuse, handles concurrent ceremonies correctly, and maintains existing passkey authentication semantics.

## Scope

**In scope:**
- Migration 033: `webauthn_challenges` table
- Replace all three dict stores with DB CRUD
- Challenge lifecycle: generate → store → verify+consume → garbage-collect
- Preserve existing three-ceremony semantics (registration / authentication / operator_registration)

**Out of scope:**
- WebAuthn ceremony flow changes (challenge format, attestation, assertion remain unchanged)
- Authentication UI redesign (PR-20)
- Session management changes
- Multi-device passkey sync

## Schema Design (W4-D03)

```sql
CREATE TABLE webauthn_challenges (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    challenge_hash VARCHAR(64) NOT NULL,  -- SHA-256 hex of challenge bytes
    purpose VARCHAR(32) NOT NULL CHECK (purpose IN ('registration', 'authentication', 'operator_registration')),
    session_id VARCHAR(255),              -- for operator_registration
    user_id UUID,                         -- for user-scoped ceremonies, FK to users(id)
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    expires_at TIMESTAMP NOT NULL,
    consumed_at TIMESTAMP
);

CREATE INDEX idx_webauthn_challenges_purpose_session ON webauthn_challenges(purpose, session_id) WHERE session_id IS NOT NULL;
CREATE INDEX idx_webauthn_challenges_purpose_user ON webauthn_challenges(purpose, user_id) WHERE user_id IS NOT NULL;
CREATE INDEX idx_webauthn_challenges_expires ON webauthn_challenges(expires_at) WHERE consumed_at IS NULL;
```

**Rationale:**
- `challenge_hash` instead of raw challenge: challenges are random bytes, hash prevents size/encoding issues
- `purpose` isolates ceremony types (registration challenge cannot be consumed by authentication)
- Dual binding keys: `session_id` for operator, `user_id` for user ceremonies
- `consumed_at` nullable: NULL = available, non-NULL = already used
- Partial indexes optimize query patterns (purpose+binding, unexpired challenges)

- [ ] **Store**: replace dict insert with DB insert:
  ```python
  def store_challenge(
      db: Session,
      challenge_bytes: bytes,
      purpose: str,
      session_id: str | None = None,
      user_id: UUID | None = None,
      ttl_seconds: int = 300  # 5 minutes default
  ) -> UUID:
      challenge_hash = hashlib.sha256(challenge_bytes).hexdigest()
      expires_at = datetime.utcnow() + timedelta(seconds=ttl_seconds)
      record = WebAuthnChallenge(
          challenge_hash=challenge_hash,
          purpose=purpose,
          session_id=session_id,
          user_id=user_id,
          expires_at=expires_at
      )
      db.add(record)
      db.commit()
      return record.id
  ```
- [ ] **Verify+Consume**: replace dict lookup with query + atomic update:
  ```python
  def verify_and_consume_challenge(
      db: Session,
      challenge_bytes: bytes,
      purpose: str,
      session_id: str | None = None,
      user_id: UUID | None = None
  ) -> bool:
      challenge_hash = hashlib.sha256(challenge_bytes).hexdigest()
      now = datetime.utcnow()
      
      # Query with purpose and binding key
      query = db.query(WebAuthnChallenge).filter(
          WebAuthnChallenge.challenge_hash == challenge_hash,
          WebAuthnChallenge.purpose == purpose,
          WebAuthnChallenge.consumed_at.is_(None),
          WebAuthnChallenge.expires_at > now
      )
      
      if purpose == "operator_registration":
          query = query.filter(WebAuthnChallenge.session_id == session_id)
      else:
          query = query.filter(WebAuthnChallenge.user_id == user_id)
      
      record = query.with_for_update().first()
      if not record:
          return False
      
      record.consumed_at = now
      db.commit()
      return True
  ```
- [ ] **Garbage collect**: add cleanup function (can be called on startup or as admin endpoint):

  def cleanup_expired_challenges(db: Session, before: datetime | None = None) -> int:

      deleted = db.query(WebAuthnChallenge).filter(
