## Objective

Establish a complete CI pipeline with four independent jobs covering frontend, backend, runtime smoke tests, and critical end-to-end flows. All jobs must pass before merge.

## Scope

**In scope:**
- CI configuration file (GitHub Actions `.github/workflows/ci.yml` or equivalent)
- Job 1: Frontend (lint, type-check, unit tests, build)
- Job 2: Backend (lint, type-check, unit tests with real PostgreSQL)
- Job 3: Runtime Smoke (production build + health checks)
- Job 4: Critical E2E (5 Playwright flows at workers=1)

**Out of scope:**
- Performance benchmarks
- Visual regression testing
- Cross-browser matrix (single browser: Chromium)
- Deployment automation
- Canary or blue-green deployment

## CI Contract (W4-D06)

| Job | Content | Environment | Acceptance |
|---|---|---|---|
| Job 1: Frontend | `npm ci` → `npx tsc --noEmit` → `npm run test:typecheck` → `npm test` → `npm run build` | Node.js (LTS) | All commands exit 0 |
| Job 2: Backend | `pip install` → `ruff check` → `mypy` → `pytest` | Python 3.11+, PostgreSQL service | pytest: 821+ passed, ≤4 failed, ≤9 skipped |
| Job 3: Runtime Smoke | `npm run build:cf` → start workerd + backend + PG → `node scripts/runtime-smoke.mjs` | Full stack (Phase 0 T-00b topology) | smoke: 0 failures, health check 200 |
| Job 4: Critical E2E | `npx playwright test --workers=1` | Chromium + full stack | 5 tests PASS (E2E-01 through E2E-05) |

Jobs run independently; failure in any job blocks merge.

**E2E-05: API failure → Error state → Retry**
```typescript
// tests/e2e/05-error-handling.spec.ts
import { test, expect } from '@playwright/test';

test('E2E-05: handle API error and retry', async ({ page }) => {
  // Intercept API call and force 503 error
  await page.route('**/api/notes', route => {
    route.fulfill({
      status: 503,
      body: JSON.stringify({ detail: 'Service unavailable' })
    });
  });
  
  await page.goto('http://localhost:8787/notes');
  
  // Should show error state
  await expect(page.locator('text=error', { timeout: 5000 })).toBeVisible();
  await expect(page.locator('button:has-text("Retry")')).toBeVisible();
  
  // Remove intercept and retry
  await page.unroute('**/api/notes');
  await page.click('button:has-text("Retry")');
  
  // Should recover
  await expect(page.locator('text=error')).not.toBeVisible();
});
```
