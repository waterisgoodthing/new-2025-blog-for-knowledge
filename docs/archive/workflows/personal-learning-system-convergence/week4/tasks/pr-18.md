# PR-18 — Legacy Cleanup

Status: **NOT_STARTED**  
Risk: MEDIUM  
Gates: G0 (requirement/domain)  
Dependencies: W4-00, PR-14, PR-15, PR-16, PR-17

## Objective

Remove dead code surfaces with three-part evidence (static reference check, test coverage verification, runtime proof) to reduce maintenance burden without breaking active functionality.

## Scope

**In scope:**
- Remove dead application code (services, endpoints, components)
- Remove associated tests of deleted modules
- Document evidence for each deletion

**Out of scope (NOT_AUTHORIZED):**
- Database column or table deletion (schema changes)
- Migration file removal (preserve migration history)
- Configuration file cleanup (keep for historical reference)
- Public-facing route removal (may have bookmarks/external links)

## Cleanup Candidates (W4-D07)

From tasks.md and baseline audit:

1. **Legacy SM-2 service** (F11) — `backend/app/services/sm2.py`
2. **Legacy review API client** — if superseded by canonical review flow
3. **Broken Dashboard quick-action tests**
4. **WIP components** — no call sites, marked TODO
5. **Unused API endpoints** — no frontend callers
6. **Duplicate analytics surfaces** — if canonical analytics replaced them

## Three-Part Evidence Requirement

Every deletion must have:

1. **Static reference check**: `grep -r <module_name>` proves no imports/calls in `backend/` and `src/`
2. **Test coverage**: deleted module's tests are also removed, or prove module was untested
3. **Runtime evidence**: recent logs or controlled runtime search proves endpoint/service was unused (for API endpoints)

1. **Frontend first**: Remove components/pages that call endpoints

4. **Services last**: Remove `backend/app/services/` services
