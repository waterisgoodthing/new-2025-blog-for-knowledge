# 需求文档：Batch 5 附件基础系统

## 背景与角色

个人管理员需要为题目草稿、正式题目和错题保存原始材料，例如截图、讲义片段或 PDF。附件属于私有学习数据，
必须可恢复、可授权、可追溯，并为后续 OCR/Capture/AI 留出安全边界。

## 功能需求

### REQ-B5-01 本地私有附件上传

- 输入：管理员上传的单个文件、原始文件名、MIME、大小。
- 处理：校验权限、类型、大小；计算 sha256；写入 local uploads；保存附件元数据。
- 输出：Attachment 元数据，默认 private。
- 失败：未登录、类型不支持、文件过大、空文件、写盘失败均返回稳定错误。
- 验收：管理员可上传；匿名不能上传；数据库不保存绝对本地路径。

### REQ-B5-02 附件列表与详情

- 输入：管理员访问列表或附件详情。
- 处理：返回分页列表、状态、文件名、MIME、大小、创建时间和关联数量。
- 输出：管理端列表与详情页可用。
- 失败：不存在返回 404，已删除/缺失文件有清晰状态。
- 验收：列表、详情和不可预览状态都有 UI 表达。

### REQ-B5-03 私有预览/读取

- 输入：管理员请求附件 content。
- 处理：通过 attachment id 查 metadata，由 storage helper 解析 storage_key 并返回文件响应。
- 输出：图片/PDF/text 可基础预览或下载；不支持类型显示不可预览。
- 失败：未登录、文件缺失、状态 deleted、MIME 不支持返回稳定错误。
- 验收：API 不接受任意 path 参数，不泄露真实磁盘路径。

### REQ-B5-04 独立业务关联

- 输入：attachment_id、target_type、target_id、purpose、sort_order。
- 处理：校验管理员、附件状态、目标存在、target_type/purpose 合法；创建或删除 AttachmentLink。
- 输出：附件可关联 question draft、question、mistake。
- 失败：目标不存在、重复关联、附件 deleted、非法 purpose 返回稳定错误。
- 验收：业务归属只存在 `attachment_links`，`attachments` 不新增 owner 字段。

### REQ-B5-05 管理端关联体验

- 输入：管理员在附件详情或业务详情页操作关联。
- 处理：可查看当前关联；可把附件关联到草稿、题目或错题；可解除关联。
- 输出：基础关联闭环可用，错误不丢失当前表单状态。
- 验收：至少一个稳定入口能完成“上传 → 关联 → 查看目标附件 → 解除关联”。

### REQ-B5-06 安全与兼容

- 输入：匿名用户、公开页面、旧 Note 数据和新 Batch 3/4 实体。
- 处理：新附件 API 全部 admin-only；不改公开 `/notes`、`/mistakes` 事实源；不暴露 storage_key。
- 输出：私有附件不泄露，旧公开页面不回归。
- 失败：任何匿名 2xx、公开 API 泄露内部字段、路径穿越可能性均阻塞。
- 验收：权限、响应字段和公开页面兼容均有证据。

## 非功能需求

- 安全：路径穿越防护、MIME/大小限制、私有默认值、后端权限为真实边界。
- 一致性：文件写入和 DB 记录需要补偿策略；写盘成功 DB 失败时清理临时文件。
- 可维护：router thin，storage helper 封装路径解析，service 管理业务状态。
- 可恢复：storage_key 可从数据库定位文件，hash 可校验内容。
- 可审查：不提交真实上传内容，验证使用临时文件或测试 fixture。

## 明确不做

- OCR、Capture Router、AI 识别或读取附件。
- PDF 自动拆页、缩略图/派生文件管线。
- Cloudflare R2、S3、对象存储、云部署。
- 公开媒体库或公开附件 API。
- 旧 Note 图片迁移到 attachments。
- 大型业务详情页重构。

## 总体验收

管理员可以上传一个允许类型文件，在 `/manage/attachments` 查看和预览，通过
`attachment_links` 关联到草稿、题目或错题；匿名用户无法上传或读取私有附件；数据库和 API
不泄露绝对路径；Batch 5 结束后仅等待用户验收，不自动进入 Batch 6。
