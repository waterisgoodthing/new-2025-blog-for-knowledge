# 页面渲染时效验证验收报告

## 验收范围与环境

- 范围：匿名 `/notes`，以及正常密码登录后的 `/manage`；
- 时间：2026-08-03；
- 环境：本地隔离 PostgreSQL、FastAPI、Next.js 开发服务器和无缓存浏览器会话；
- 数据：空隔离数据库，无真实用户内容或账号；
- 认证：临时管理员正常登录，`AUTH_BYPASS=false` 且 `AUTH_BYPASS_ALLOW=false`。

## 方法

- 每个场景 5 个新的浏览器会话；
- 使用浏览器 Navigation Timing 与 Resource Timing；
- 对主内容使用真实 DOM 断言，不以 HTTP 200 或页面外壳代替；
- 匿名场景断言公开空态；管理员场景断言“管理面板”和“还没有内容”；
- 记录公开页认证探测、接口状态与异常。
