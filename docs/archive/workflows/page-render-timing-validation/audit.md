# 预执行审计

## 已确认

- 前端开发脚本为 `npm run dev`，默认端口为 `2025`；
- 前端示例配置将 API 指向本地 `http://localhost:8000`；
- 后端 CLI 包含临时管理员创建与禁用命令；
- 后端认证绕过由 `AUTH_BYPASS` 与 `AUTH_BYPASS_ALLOW` 双开关共同控制。
- 当前没有进程监听 `2025`、`3000`、`3001`、`8000`、`8001` 或 `5432`。
- `/notes` 的主内容由 `useNoteIndex` 提供；列表、明确空态或错误态出现且“加载中...”消失后才视为 content-ready。
- `/manage` 先调用 `getMe` 判断会话，未登录时显示用户名密码登录表单；成功登录后进入管理页内容。

## 尚未确认

- 当前本机是否已有占用端口的前后端进程；
- 可用于隔离验证的数据库配置和服务端口；
- `/notes`、`/manage` 在当前数据集上的实际就绪 DOM 条件；
- 正常登录后的真实加载基线。

这些项目只能在获批后通过隔离运行环境验证。
