# 页面渲染时效验证要求

## 功能性要求

- 记录未登录用户访问 `/notes` 的内容完成可用时间；
- 记录管理员正常登录后 `/manage` 的内容完成可用时间；
- 分开报告浏览器导航时间、内容就绪时间与关键网络请求耗时；
- 对每个页面就绪判定保留可复核的 DOM 条件与截图/日志证据；
- 登录验证必须经由项目既有的正常登录路径，不能使用 `AUTH_BYPASS`。

## 环境与安全要求

- 使用独立的本地端口、输出目录、测试数据库与浏览器上下文；
- 只创建验证用临时管理员，不能读取或输出真实凭据；
- 每轮验证后清理临时管理员和测试进程；
- 任何已有服务、用户工作区文件、数据库或部署配置均不得被修改。

## 报告要求

- 明确说明运行日期、页面、环境、样本数和冷/热访问定义；
- 分别列出匿名页与管理员登录后页面的结果；
- 对异常样本和失败请求给出原因，不将其静默排除；
- 仅在结果完整且环境满足隔离条件时给出结论。
