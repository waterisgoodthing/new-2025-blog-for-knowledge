# 残余风险

## RISK-RT-001

- 风险类型：性能与体验；
- 风险描述：公开 `/notes` 仍会请求 `GET /api/auth/me`，未登录时返回 401。页面优雅降级，但会增加一次请求和后端认证失败日志；
- 影响范围：公开笔记页首次加载；
- 严重程度：低；
- 当前状态：未处理；
- 建议措施：在独立获批的前端权限/加载优化任务中，使公开页仅在需要管理员功能时探测会话，或把匿名会话结果作为无错误的显式状态处理；
- 是否进入下一轮需求：是。

- 影响范围：本报告全部数值的解释边界；
- 严重程度：中；
- 当前状态：部分处理；
- 建议措施：如需发布门槛，另建生产构建且接近真实数据量的性能验收任务；
- 是否进入下一轮需求：是。

- 风险类型：环境兼容性；
- 风险描述：开发服务器以 `127.0.0.1` 访问时拦截开发资源，导致客户端未 hydration；统一使用 `localhost` 后恢复。该现象不代表生产故障，但本地验证必须保持前端和 API 的 Cookie 同站点主机名一致；
- 影响范围：本地浏览器验证与管理员会话测试；
- 严重程度：低；
- 当前状态：已缓解；
- 建议措施：将本地验证主机名约定写入后续测试运行说明；
- 是否进入下一轮需求：否。
