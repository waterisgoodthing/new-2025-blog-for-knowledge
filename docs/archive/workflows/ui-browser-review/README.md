# UI Browser Review

## Goal

Perform a read-only, evidence-based UI/UX acceptance review of the current frontend in a real browser. Capture desktop and mobile screenshots, inspect console/network/static-resource behavior, and publish the requested review artifacts under `docs/ui-review/`.

## Domains

All public frontend routes and any accessible management routes; no business domain code will be changed.
