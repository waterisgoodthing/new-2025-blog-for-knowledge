# Personal Learning System V2 UI 设计

## 1. 设计目标

UI 不是把现有页面重新换皮，而是围绕“今天要做什么”重排学习动作。界面需要让用户在一个上下文中完成采集、整理、关联、复习和总结；治理、成本、Provider 状态和审计信息留在管理端。

视觉基线：紧凑、安静、可扫描；优先使用列表、分栏、时间线和上下文侧栏；卡片只用于重复对象、弹层和确实需要边界的工具。页面不能使用营销式 Hero，也不把学习流程拆成互相嵌套的卡片。

## 2. 全局壳层

### 桌面布局

```text
┌─────────────────────────────────────────────────────────────┐
│ Logo / 今日   搜索   ⌘K 命令面板   快速记录   用户菜单       │
├──────────────┬──────────────────────────────────────────────┤
│ 一级导航      │ 页面标题 / 面包屑 / 当前上下文 / 操作区       │
│ 今日          ├──────────────────────────────────────────────┤
│ 采集          │ 主内容区                                      │
│ 学习          │                                                │
│ 复习          │                                                │
│ 知识库        │                                                │
│ 项目          │                                                │
│ 发布          │                                                │
│──────────────│                                                │
│ 系统治理      │                                                │
│ AI / 审计     │                                                │
└──────────────┴──────────────────────────────────────────────┘
```

### 移动布局

底部固定三个高频动作：今日、采集、复习；其余入口通过菜单抽屉访问。采集按钮必须提供图标和可访问名称，抽屉打开时处理焦点循环、Escape 关闭和路由切换后自动关闭。

## 3. `/today` 今日工作台

首屏结构：

```text
┌──────────────────────────────────────────────────────────┐
│ 早上好，今天先处理 3 个行动项                 [快速记录] │
├──────────────────────┬───────────────────────────────────┤
│ 今日复习              │ 待整理采集                         │
│ 12 个到期 / 2 个逾期  │ 3 张图片 · 1 条文字                 │
│ [开始复习]            │ [打开采集箱]                       │
├──────────────────────┼───────────────────────────────────┤
│ 最近错题              │ 进行中的学习 / 项目                 │
│ 概念缺失 4 · 计算 2   │ 数据结构 · 二叉树                   │
│ [查看错题]            │ [继续学习]                         │
├──────────────────────────────────────────────────────────┤
│ AI 待审核建议：关系 2 条 / 总结 1 条          [去审核]      │
└──────────────────────────────────────────────────────────┘
```

状态要求：加载时显示结构化骨架；无数据时显示下一步动作；局部 API 失败只影响对应区块；数量未知时不显示为 0；复习开始后保留返回今日的上下文。

## 4. `/capture` 采集箱

采集箱采用“输入方式 + 待处理列表 + 右侧详情”的工作台：

```text
┌────────────────────────────────────────────────────────────┐
│ 采集箱                         [文字] [截图] [文件] [快速记] │
├──────────────┬──────────────────────────┬─────────────────┤
│ 筛选          │ 待处理列表               │ 当前采集详情     │
│ 全部          │ ● 二叉树题目截图         │ 原图 / OCR 文本  │
│ 图片          │   需要校正 · 2 分钟前     │ 题干             │
│ 文本          │ ● 一个待研究问题         │ 选项             │
│ 失败          │   未分类                 │ 用户校正区       │
│ 已整理        │                          │ [保存草稿]       │
│               │                          │ [建立知识关联]   │
│               │                          │ [生成错题]       │
└──────────────┴──────────────────────────┴─────────────────┘
```

图片审核必须同时展示原图和结构化字段；AI 建议使用可接受/拒绝的行级控件；保存失败时保留用户输入和本地草稿状态。

│ 数据结构 / mastery: 62 / 重要性: 高                         │
├──────────────────────────┬─────────────────────────────────┤

│                            │ 相关题目：12                     │
│                            │ 相关错题：4                      │
│                            │ 最近复习：昨天                   │
├──────────────────────────┴─────────────────────────────────┤

## 6. 编辑器

```text
┌────────────────────────────────────────────────────────────┐
│ 二叉树遍历.md   [自动保存] [预览] [发布]                     │
├──────────────────────────────┬─────────────────────────────┤
│ Markdown 编辑区               │ 渲染预览                      │
│ [[二叉树]]                    │ 二叉树                        │
│ ```python                     │ 公式 / 代码 / 图片             │
│ ...                           │                              │
├──────────────────────────────┴─────────────────────────────┤
│ 属性 | 知识点 | 反向链接 | 引用 | 错题 | 版本 | AI 建议       │
└────────────────────────────────────────────────────────────┘
```

WikiLink、标签和模板使用自动补全；版本历史支持差异查看和恢复；AI 修改必须以建议或对比结果呈现，不能静默覆盖正文。

## 7. 复习界面

复习页采用单任务专注模式：题目/知识点内容在中央，结果按钮在底部，右侧显示当前进度、来源和关联错题。结果按钮统一为“遗忘、困难、记住、简单”，提交后显示下一次复习时间并允许撤销本次记录。

## 8. 响应式与可访问性

- 桌面使用侧栏 + 主内容 + 上下文栏；窄屏改为单列和底部动作栏。
- 所有图标按钮提供可访问名称和 tooltip；颜色不作为唯一状态信息。
- 长标题、长错误摘要、公式、代码和中文字段必须换行或滚动，不得撑破布局。
- 键盘可完成导航、采集、审核、编辑和复习；弹层有焦点约束。
- 公开内容不显示编辑、删除、AI 生成和复习提交控件。

## 9. UI 实现拆分

每个页面任务都必须同时交付：路由页面、route-specific components、状态映射、API loading/empty/error/busy/success、键盘与窄屏验收。共享组件只放入 `src/components/` 或已有 manage-scoped 组件目录，不把 API 调用写进展示组件。

## 10. Learning Timeline

Learning Timeline 是跨领域的只读时间线，不拥有任何业务事实。它按事件时间聚合 Review、Capture、Publish、Project 和 AI 审核结果，点击后回到对象详情。

```text
┌────────────────────────────────────────────────────────────┐
│ 学习时间线                     [今天] [本周] [本月] [筛选]    │
├──────────────┬─────────────────────────────────────────────┤
│ 类型筛选      │ 今天                                         │
│ 全部          │ 09:20 复习：二叉树遍历          记住          │
│ 采集          │ 10:05 采集：题目截图              已整理        │
│ 学习          │ 11:30 AI 建议：新增前置关系      待审核        │
│ 复习          │                                             │
│ AI            │ 昨天                                         │
│ 发布          │ 18:40 发布：数据结构学习总结      已发布        │
│ 项目          │ 20:10 项目：完成 API 合同          已完成        │
└──────────────┴─────────────────────────────────────────────┘
```

时间线状态：时间范围无数据显示建议动作；单个来源失败显示局部失败并允许重试；私有事件只在管理员会话中返回；移动端改为单列时间线和顶部筛选抽屉。

后端建议函数：`TimelineService.list_events()`、`TimelineService.apply_range()`、`TimelineService.apply_type_filter()`、`GET /api/timeline`。该服务只能读取各 Context 的事件/摘要 contract，不直接修改 Review、Capture 或 Publish 对象。

## 11. Command Palette

Command Palette 通过 `⌘K` 或 `Ctrl+K` 打开，支持搜索命令和对象。命令执行后关闭面板并保留来源页上下文。

```text
┌──────────────────────────────────────────────┐
│ 搜索命令或知识点...                           │
├──────────────────────────────────────────────┤
│ 最近使用                                       │
│ 进入今日                                       │
│ 新建快速记录                                   │
│ 上传截图                                       │
│ 开始今日复习                                   │
│ 搜索知识点                                     │
│ 打开学习时间线                                 │
│ ---------------------------------------------- │
│ 导航：采集 / 学习 / 知识库 / 项目 / 发布       │
└──────────────────────────────────────────────┘
```

命令分类：导航、创建、搜索、学习、复习、审核和发布。每个命令必须标记权限、快捷键、失败反馈和不可用原因；未登录用户只能看到公开导航和公开搜索。键盘支持上下选择、Enter 执行、Escape 关闭，移动端使用搜索按钮打开同一面板。

后端不为每个命令创建独立业务接口；Command Palette 复用已有 API client。可选的 `GET /api/commands?q=` 只返回当前用户有权限执行的命令描述，不返回私有对象正文。
