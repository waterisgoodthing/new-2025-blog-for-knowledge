## RISK-B9-001 ai.py 瘦身引入回归

| 字段 | 内容 |
| --- | --- |
| 风险类型 | 回归 / 可维护性 |
| 风险描述 | `ai.py`（1605 行）中的 LaTeX 修复、deterministic repair、parse result 等业务逻辑抽离到 service 层时，可能改变行为或遗漏依赖。 |

## RISK-B9-002 调用日志写入性能

| 字段 | 内容 |
| --- | --- |
| 风险类型 | 性能 |
| 风险描述 | 每次 AI 调用额外写入一条 DB 记录，增加约 5-10ms 延迟。高频调用场景可能累积。 |
| 严重程度 | 低 |
| 当前状态 | 可接受 — AI 调用本身 latency 远高于 DB 写入 |
| 建议措施 | 使用独立 AsyncSession（不阻塞主调用事务）。Batch 12 可改为异步队列写入。 |

## RISK-B9-003 流式调用日志丢失

| 字段 | 内容 |
| --- | --- |
| 风险类型 | 数据完整性 |
| 风险描述 | 流式调用在流结束后写日志，如果客户端断开连接或服务异常，日志可能丢失。 |
| 严重程度 | 低 |
| 当前状态 | 可接受 — 流式调用占比低，且不影响主功能 |
| 建议措施 | 在 finally 块中写日志；Batch 11 审计时补充。 |
