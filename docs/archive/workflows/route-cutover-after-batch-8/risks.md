# Risks：Route Cutover Sprint 风险记录

> 关联：[README.md](./README.md) | [handoff.md](./handoff.md)
> 用法：实施前确认风险项与缓解措施；用户已确认的风险不作为阻塞。

## 一、用户已确认的风险（不作为阻塞）

### R-1 旧数据编辑能力丢失

- **描述**：旧 `Note` / 旧错题可能无法继续通过旧 `write-*` 编辑。下线后旧编辑入口停用。
- **影响**：历史 `Note(type="mistake")` 内容若需修改，将缺少旧编辑入口。
- **用户确认**：不作为阻塞风险。
- **缓解**：保留旧数据只读展示；如需编辑可在后续迭代提供迁移到新 `mistakes` 的工具。

### R-2 旧编辑能力丢失不回滚

- **描述**：本轮不保留复杂兼容层，旧 `write-*` 重定向 / 提示后不再写旧 `Note`。
- **影响**：依赖旧写入路径的自动化或书签将失效。
- **用户确认**：不作为阻塞风险。
- **缓解**：提示页说明新入口；记录受影响入口清单。

## 二、需关注的风险

### R-3 旧书签失效

- **描述**：用户旧书签访问 `write-*` 可能进入提示页或重定向。
- **影响**：旧书签用户体验下降。
- **缓解**：使用重定向或带新入口链接的提示页，不直接 404。

### R-4 公开错题策略变更

- **描述**：若选择方案 B（关闭 `/mistakes` 公开），公开访客将不再看到错题集。
- **影响**：已索引的 `/mistakes` 公开页行为变化；访客无法浏览错题。
- **缓解**：明确记录决策；若关心 SEO，使用 noindex 或重定向而非 404。

### R-5 SEO 影响

- **描述**：下线路由可能影响已有索引。
- **影响**：搜索引擎收录的 `write-*` / `/mistakes/review` 链接行为变化。
- **缓解**：
  - 对有等价新入口的路由用 301 重定向。
  - 对纯下线路由用 noindex 提示页。
  - 不直接产生大量 404。

### R-6 无限"验证中"

- **描述**：若旧 `write-*` 页面残留 `AuthGate` 骨架但被重定向打断，可能出现无限加载。
- **影响**：用户访问旧路由卡在"验证中"。
- **缓解**：重定向在页面渲染前生效；提示页不依赖 admin 会话校验才渲染。

### R-7 公开页 admin API 噪音

- **描述**：公开页若仍默认请求 admin API，匿名访问会产生 401/403。
- **影响**：控制台噪音、无效请求、潜在信息泄露。
- **缓解**：admin-only SWR `enabled=false`；公开页只保留 PublicList / PublicDetail。

### R-8 旧 /manage 依赖未清

- **描述**：旧 `/manage`（`src/app/manage/page.tsx`）可能仍有用户依赖。
- **影响**：直接重定向可能打断既有工作流。
- **缓解**：分两步——先加提示 + 新入口按钮，确认无依赖后再重定向。

### R-9 /mistakes 决策未确认即实施

- **描述**：若 D-0 未确认就改 `/mistakes`，可能误关闭公开内容或误暴露私有数据。
- **影响**：权限或展示与用户预期不符。
- **缓解**：tasks.md P0-05 明确依赖 D-0，未确认前跳过相关改动。

## 三、不在本轮处理的风险（记录留档）

- 旧 `Note(type="mistake")` → 新 `mistakes` 的数据迁移（本轮明确不做）。
- 后端注册与 CORS 的生产化（已知架构债，本轮不处理）。
- Podcast 作为一等域类型（已知架构债，本轮不处理）。
