# 需求文档：Batch 1 UI 壳层

## 1. 背景

MVP 后续批次需要稳定的管理导航与页面容器，但当前 `/manage` 是单页标签式旧管理
面板，首页也没有通往新学习工作区的轻入口。本批只搭壳，不提前实现业务。

## 2. 使用者

- 公开访客：继续浏览低密度首页与公开内容。
- 个人管理员：从首页进入受保护的学习管理工作区。
- 后续开发者：在统一壳层中实现 Batch 2 至 Batch 6 页面。

## 3. 功能需求

### REQ-B1-01：首页学习轻入口

- 输入：公开首页。
- 处理：显示待复习、待审核、进入学习空间、上传资料四个静态入口。
- 输出：导航到对应 `/manage/*` 页面。
- 失败处理：未登录由目标管理页跳转 `/manage`；首页自身不报管理员 API 错误。
- 验收：首页风格和密度不变，无真实数据请求。

### REQ-B1-02：统一管理壳层

- 输入：任一新 `/manage/*` 工作区路由。
- 处理：由统一 layout 渲染 Sidebar、Topbar 和页面内容。
- 输出：一致、可导航的管理工作区。
- 失败处理：无权限时不渲染工作区，跳转现有 `/manage` 登录入口。
- 验收：所有目标子路由共享壳层且当前导航项明确。

### REQ-B1-03：Dashboard 占位

- 输入：管理员访问 `/manage/dashboard`。
- 处理：展示工作区说明和静态状态占位。
- 输出：可理解的管理入口。
- 失败处理：任何未接数据明确写“尚未接入”，不伪造数量。
- 验收：不调用业务 API，不显示复杂图表。

### REQ-B1-04：后续页面占位

- 输入：管理员访问 drafts、questions、mistakes、attachments、subjects、review。
- 处理：显示统一 header、批次归属和非交互占位。
- 输出：无死链的未来工作区骨架。
- 失败处理：不得提供会触发未实现操作的按钮；提及真实动作时必须标注“后续批次启用”。
- 验收：所有占位页视觉一致、文案准确且不报错。

### REQ-B1-05：旧 `/manage` 兼容

- 输入：访问 `/manage` 或使用既有登录、标签功能。
- 处理：保留现有页面与后端认证流程。
- 输出：旧管理功能继续可达。
- 失败处理：不得让 AuthGate 重定向到自身；不得删除、迁移、拆分、重命名或重构
  `src/app/manage/page.tsx` 的旧业务逻辑。
- 验收：登录入口与旧管理面板不因新壳层失效。

### REQ-B1-06：公开读取保护

- 输入：未登录访问公开博客、笔记和错题。
- 处理：保持原公开路由行为。
- 输出：公开读取不受新管理布局影响。
- 失败处理：管理入口失败不得污染公开页面。
- 验收：`/blog`、`/notes`、`/mistakes` 未被 AuthGate 包裹。

## 4. 非功能需求

- 可访问性：图标入口有文本或 accessible name；键盘可访问。
- 响应式：桌面与移动端均不溢出或遮挡关键内容。
- 一致性：复用现有颜色 token、圆角和玻璃质感。
- 性能：不引入新依赖或首页数据请求。
- 安全性：后端鉴权不变，AuthGate 只承担页面体验。
- 可维护性：管理组件放在 `src/app/manage/components/`，不提升为无复用证据的全局组件。

## 5. 本批不做

- 不实现真实草稿、题库、错题、复习、附件或科目业务。
- 不调用真实统计、复习、草稿或附件 API。
- 不改后端、数据库、迁移、依赖或配置 JSON。
- 不重构或删除 `/manage` 旧标签式功能。
- 不修改首页配置 JSON、旧卡片顺序、拖拽逻辑、布局算法或全局视觉 token。
- 首页除新增并接入 `LearningSpaceCard` 外，不改造现有卡片系统。
- 占位页不得创建真实业务动作按钮。
- 不做 AI、OCR、表单、复杂图表或最终视觉收口。
- 不修改公开博客、笔记、错题业务页面。

## 6. 验收标准

1. 首页只增加约定的四个轻入口，保持原视觉与低密度。
2. `/manage/dashboard` 及六个占位子页共享统一壳层。
3. Sidebar、Topbar、PageHeader 可复用且当前导航清楚。
4. 未登录访问子页跳转 `/manage`，不出现重定向循环。
5. `/manage` 旧登录与管理功能保持可用。
6. 新页面没有真实业务请求或假数据。
7. 公开博客、笔记、错题读取未受损。
8. TypeScript、桌面/移动浏览器和权限验收有记录。
9. 若 TypeScript 失败，验证记录包含第一条失败、与本批文件的关系、新增错误判断和
   补充验证，且不伪称通过。
