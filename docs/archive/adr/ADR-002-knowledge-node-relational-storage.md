# ADR-002：KnowledgeNode 使用关系模型，不以 GraphDB 作为事实存储

- 状态：Accepted
- 日期：2026-07-13
- 范围：Knowledge、Content、Search

## 决策

知识节点、别名、关系边和内容关联使用 PostgreSQL 关系表保存。图谱是从关系数据生成的查询投影，不引入 Neo4j 或其他图数据库作为首版事实存储。

## 原因

当前规模更需要可迁移、可审计、可与内容/题目/错题/复习使用同一事务边界，而不是额外的图数据库运维和双写一致性。

## 后果

关系查询必须提供索引、局部图谱投影和反向链接重算；复杂图算法暂缓。未来若规模和查询证据证明需要 GraphDB，必须通过新 ADR 和迁移演练引入。
