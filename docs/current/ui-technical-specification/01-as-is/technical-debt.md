## D1：视觉不一致

### D1-001：Token 系统分裂

**优先级**：P0  
**发现时间**：2026-10-15  
**位置**：`site-content.json` + `theme.css` + `ui-v2/tokens.css`

**描述**：3 套 Token 系统并存，品牌色冲突（`#2fcbe7` vs `#35bfab`）

**影响**：
- 样式维护成本高
- 设计一致性无法保证
- 新功能不知道用哪套 Token

**修复建议**：Phase 1（VSC-02）合并为 1 套

**状态**：📋 待修复（Phase 1）

---

### D1-002：按钮样式不统一

**优先级**：P1  
**发现时间**：2026-10-15  
**位置**：多个组件

**描述**：
```bash
grep -r "className.*rounded-lg.*bg-" src/components | wc -l
# 结果：34 处硬编码
```

**影响**：同样功能的按钮在不同页面样式不同

**修复建议**：统一使用 UI V2 Button

**状态**：📋 待修复（Phase 2+）

---

### D1-003：卡片圆角不统一

**优先级**：P1  
**位置**：多个页面

**描述**：
- 部分卡片 `rounded-lg`（12px）
- 部分卡片 `rounded-md`（8px）
- 部分卡片硬编码 `border-radius: 16px`

**影响**：视觉不一致

**修复建议**：统一使用 `--radius-md` (12px)

**状态**：📋 待修复（Phase 2+）

---

### D1-004：间距不一致

**优先级**：P2  
**位置**：多个页面

**描述**：
- 部分用 Tailwind 工具类（`gap-4`）
- 部分硬编码（`gap: 20px`）
- 部分用非标准值（`gap: 18px`）

**影响**：视觉节奏不一致

**修复建议**：统一使用 spacing token（4px 倍数）

**状态**：📋 待修复（Phase 2+）

---

### D1-005：阴影不一致

**优先级**：P2  
**位置**：Card/Modal/Drawer

**描述**：多种阴影定义，无统一标准

**修复建议**：统一使用 `--shadow-*` token

**状态**：📋 待修复（Phase 2+）

---

### D1-006：字体大小不一致

**优先级**：P1  
**位置**：标题、正文

**描述**：
- 部分用 Tailwind（`text-lg`）
- 部分硬编码（`font-size: 18px`）
- 部分用非标准值（`font-size: 17px`）

**修复建议**：统一使用流式字号（`--text-*`）

**状态**：📋 待修复（Phase 2+）

---

### D1-007：色彩对比度不足 [需验证 L3]

**优先级**：P0

**描述**：灰色文字在白色背景上对比度可能 < 4.5:1

**修复建议**：Contrast Checker 检测，调整颜色

### D1-008：Editorial 风格缺失
