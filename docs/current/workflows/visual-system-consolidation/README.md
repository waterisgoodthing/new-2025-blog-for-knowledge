# Visual System Consolidation

## Goal

Turn the current mixture of runtime theme variables, repeated translucent surfaces, navigation variants, page-specific overlays, and context menus into a minimal, evidence-backed visual system.

## Touched Domains

- shared frontend presentation infrastructure;
- public navigation and content-detail navigation;
- administrator workspace navigation;
- shared Modal, Drawer, Popover, Context Menu, and mobile Action Sheet behavior;
- responsive, keyboard, focus, reduced-motion, and permission-aware UI behavior.

## Boundaries

This workflow does not authorize a site-wide redesign, route change, CSS rewrite, dependency addition, authentication change, or immediate replacement of every existing component. Public reading must remain public and protected actions must remain protected by backend authorization.
