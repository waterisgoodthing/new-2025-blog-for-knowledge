# UI 升级 — 需求文档 v2.0

> 版本: 2.0
> 日期: 2026-06-04
> 关联设计文档: `docs/ui-upgrade-design.md` v2.0
> 关联差异报告: `docs/ui-upgrade-diff-report.md`

---

## 1. 项目背景

### 1.1 现状

系统功能基本完整，但作为唯一用户每天使用时存在 11 个阻断或体验断裂问题。

### 1.2 目标

将系统从"功能基本存在"调整为"每天使用可理解、可预测、不卡住、能正常渲染"。

### 1.3 范围

**覆盖**:
- 左侧导航栏溢出和跳转修复
- My Blog 跳转语义统一
- 错题页 AI 入口增强
- 思维导图渲染修复
- Markdown 标题 # 装饰移除
- 写作入口文案（可选）
- 左侧标签按页面动态过滤
- 设置保存错误拆分
- Live2D 状态页
- 设置管理页集中化

**不覆盖**:
- 新增功能（ECharts、新页面等）
- 首页布局编辑改造
- 后端数据模型变更
- 多用户协作

## 2. 功能需求

### FR-1: 左侧导航栏溢出修复

**优先级**: P0

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| FR-1.1 | 导航容器添加 `max-height: calc(100vh - 32px)` | 导航在小屏幕不被裁切 |
| FR-1.2 | 导航列表区域添加 `overflow-y-auto` | 内容过多时可滚动 |
| FR-1.3 | 头像区域固定，导航列表可滚动 | 头像始终可见 |
| FR-1.4 | 添加 `left-2` 或 `ml-2` 左侧间距 | 导航不紧贴屏幕边缘 |
| FR-1.5 | /、/notes、/mistakes、/manage 页面导航定位一致 | 所有内页导航位置统一 |

---

### FR-2: 导航跳转修复

**优先级**: P0

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| FR-2.1 | `motion.div`（active 胶囊）添加 `pointer-events-none` | 不拦截 Link 点击 |
| FR-2.2 | 标签展开动画改为 `opacity + x` 位移（不改变 width） | 避免布局抖动导致点击偏移 |
| FR-2.3 | `Link` 组件添加 `relative z-10` | 确保 Link 在装饰元素之上 |
| FR-2.4 | 点击任意导航项都能稳定跳转到目标页面 | 逐个点击测试通过 |

---

### FR-3: My Blog 跳转语义统一

**优先级**: P0

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| FR-3.1 | 头像 + 站点名点击始终跳转首页 `/` | 行为唯一且可预测 |
| FR-3.2 | 在导航列表中添加"网站设置"入口按钮 | 独立设置入口 |
| FR-3.3 | "网站设置"按钮点击调用 `setConfigDialogOpen(true)` | 打开设置对话框 |
| FR-3.4 | 设置入口使用 `Settings` 图标 + "网站设置" 文案 | 语义明确 |
| FR-3.5 | 设置入口有 `aria-label` 和 `title` | 无障碍通过 |

---

### FR-4: 错题页 AI 入口增强

**优先级**: P0

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| FR-4.1 | 主按钮文案改为"AI 智能解析题目" | 文案更具体 |
| FR-4.2 | 面板描述文案增加操作说明 | 用户知道如何使用 |
| FR-4.3 | 增加"AI 生成解析"次级按钮 | 只填充 analysis 字段 |
| FR-4.4 | 增加"AI 生成知识点"次级按钮 | 只填充 knowledge_points 字段 |
| FR-4.5 | 次级按钮复用 `analyzeText` API，结果只更新对应字段 | 不新增 API |
| FR-4.6 | 次级按钮仅在题目文本（`pasteText`）或已上传图片（`uploadedImages`）存在时启用 | 无输入时禁用 |
| FR-4.7 | 次级按钮调用中显示 loading 状态（spinner + "生成中..."） | 用户知道正在处理 |
| FR-4.8 | 次级按钮失败时不清空原字段，只显示 toast 错误 | 不丢失已有内容 |
| FR-4.9 | 次级按钮不需要二次确认（因为只覆盖目标字段，不覆盖全部） | 直接执行 |

### FR-5: 思维导图渲染修复

**优先级**: P0

| 编号 | 需求 | 验收标准 |
|------|------|---------|
| FR-5.1 | 移除 `loadFailed` 永久失败标志，允许重试 | 加载失败后刷新页面可重试 |
| FR-5.2 | SVG 容器添加 `minWidth: 300` | 容器不为 0 宽度 |
| FR-5.3 | 添加 SSR 保护（`mounted` state） | 服务端渲染不报错 |
| FR-5.4 | 错误状态显示"重试"按钮 | 用户可手动重试 |
| FR-5.5 | 重试次数限制（最多 3 次） | 防止无限重试 |
| FR-5.6 | 错误时降级显示原始 Markdown 代码 | 不白屏 |

## 3. 非功能需求

### NFR-1: 向后兼容

- 现有导航链接行为不变（除了修复跳转问题）
- 首页 NavCard 拖拽编辑功能不受影响
- 写作页 mini NavCard 保留
- KnowledgeSidebar 功能不受影响
- 旧 Mermaid mindmap 代码块仍正常渲染

### NFR-2: 可访问性

- 新增的"网站设置"按钮有 `aria-label` + `title`
- 所有修改的按钮/链接保持或新增无障碍属性

### NFR-3: 性能

- 不引入新依赖
- 不增加首屏 bundle 大小
- Markmap 懒加载保持不变

---

## 4. 约束

1. **不引入新依赖**: 所有修复使用现有库和组件
2. **不改动后端 API**: 所有修复在前端完成（除 FR-4.5 复用现有 API）
3. **不改动首页布局**: NavCard 拖拽编辑功能不受影响
4. **不改动写作页**: mini NavCard 保留
5. **样式一致性**: 所有修改遵循半透明卡片、圆角、玻璃风格
