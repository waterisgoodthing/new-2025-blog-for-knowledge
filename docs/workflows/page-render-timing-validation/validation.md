| 2 | 92.8 | 179.4 | 362.8 | PASS |

| 4 | 86.7 | 174.8 | 332.1 | PASS |

| 中位数 | 90.0 | 179.4 | 284.9 | PASS |

结论：在本地隔离的开发服务器与空数据集上，匿名主内容的可复核就绪时间基线为 **252.3–362.8 ms**（中位数 **284.9 ms**）。该时间以笔记 API 的 `responseEnd` 为边界，随后已通过真实 DOM 验证空态；页面没有应用内渲染标记，因此不能将该数值误称为精确的 React 提交时刻。

证据：[匿名空态截图](assets/anonymous-notes-empty.png)。
