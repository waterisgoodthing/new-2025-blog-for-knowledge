# 页面渲染时效验证

## 目标

在隔离的本地运行环境中，采集并评估：

1. 未登录访客进入公开内容页后，主内容完成可用的时间；
2. 管理员提交正常登录后，管理页主内容完成可用的时间。

本任务只做真实性能验证和证据记录，不改变前端、后端、认证、数据库结构或部署配置。

## 触及领域

- frontend：公开页面与管理页面的加载时序；
- auth：正常登录后的页面就绪时序；不改变认证逻辑；
- shared infrastructure：隔离的本地验证进程、测试账户与浏览器上下文。

## 当前状态

`COMPLETE` — 已完成隔离环境中的浏览器时效验证、证据记录和清理；结果只适用于本地空数据开发基线。

## 验证范围

- 公开基线路由：`/notes`；
- 管理员登录与登录后基线路由：`/manage`；
- 默认仅测隔离本地环境，不能把结果表述为公网性能。

若路由实际无法代表用户关注的页面，任务 R0 会先记录替换理由，再执行后续步骤。
